#recture
##什么是recture
recture 是一个截长图的工具。
##怎么用
正常情况下，你可以使用手动截图模式。
先按快捷键开始截图，然后按截图快捷键将截图区域捕获并添加到截图成果里，然后滚动到下一处。
完成后就可以停止截图。

如果您使用的是文本编辑器，那么就可以使用自动滚动。

自动截图模式当前还在实验中，不保证成果的质量。
